# คู่มือการตรวจสอบ IT สำหรับผู้เริ่มต้น

เว็บไซต์ภาษาไทยสำหรับศึกษาและเตรียมงานตรวจสอบเทคโนโลยีสารสนเทศ ครอบคลุม ITGC, Application Audit, วิธีทดสอบ, หลักฐาน, Checklist, คลังคำศัพท์, ขั้นตอนการทำงาน และตัวอย่างข้อตรวจพบ

ข้อมูลที่กรอกใน Checklist และกล่องบันทึกจะเก็บในเว็บเบราว์เซอร์ของผู้ใช้แต่ละคน ผู้ใช้สามารถกด **บันทึกไฟล์ (.html)** เพื่อสำรองข้อมูลของตนเองได้

## ไฟล์หลัก

- `index.html` — คู่มือหลัก
- `RCM_ITGC_GeneralBusiness_UNVS.html` — ตารางความเสี่ยงและจุดควบคุม
- `IT_Audit_Glossary_TH.md` — คลังคำศัพท์ฉบับข้อความ
- `IT_Audit_Overview_Map_TH.md` — ภาพรวมขอบเขตงานตรวจ
