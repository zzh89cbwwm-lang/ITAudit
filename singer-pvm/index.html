สำรวจพื้นที่

Owner · ทีม PVM
Key takeaway
“ทำเลต้องผ่านการประเมิน ก่อนเริ่มเรื่องสัญญา”
What happens
  1. สำรวจพื้นที่
  2. เก็บข้อมูลเจ้าของพื้นที่
  3. ประเมินศักยภาพทำเล
  4. ติดต่อเจ้าของพื้นที่เพื่อขอติดตั้งตู้
Documents / Systems
Checklist ประเมินพื้นที่ภาพ/หลักฐาน Locationข้อมูลเจ้าของพื้นที่
Purpose: ให้ข้อมูลและหลักฐานของขั้นตอนนี้เชื่อมต่อไปยัง Process ถัดไปได้โดยไม่ขาดช่วง
Control / Accounting
  • ใช้เกณฑ์ประเมินพื้นที่ก่อนดำเนินการต่อ
  • ข้อมูล Location ต้องนำไปเชื่อมกับสัญญาและ Asset ได้

ติดตั้งตู้น้ำมัน

Owner · บัญชี / จัดซื้อ / ทีม PVM
Key takeaway
“ระบบกับของจริงต้องตรงกัน ก่อนเปิดขาย”
What happens
  1. บัญชีสร้าง Location และโอนย้ายตู้ใน ERP
  2. เติมน้ำมัน 0.01 ลิตรในระบบตาม Flow
  3. จัดซื้อสร้าง Item Code
  4. PVM เติมน้ำมันเข้าตู้
  5. ติดตั้ง ทดสอบ ตั้งค่าราคา
  6. ส่งมอบผู้ดูแล
Documents / Systems
ERPItem MasterEmail อนุมัติExcel จุดติดตั้งTimestamp Photo
Purpose: ให้ข้อมูลและหลักฐานของขั้นตอนนี้เชื่อมต่อไปยัง Process ถัดไปได้โดยไม่ขาดช่วง
Control / Accounting
  • ERP Location + Serial + จุดติดตั้งจริงต้องสัมพันธ์กัน
  • ต้องมีหลักฐานการติดตั้ง/ทดสอบ/ตั้งค่า
